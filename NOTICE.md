# Third-party assets

## Franka Emika Panda model

The robot model and meshes in `assets/franka_emika_panda/` are from the [MuJoCo Menagerie Panda model](https://github.com/google-deepmind/mujoco_menagerie/tree/main/franka_emika_panda). They are distributed under Apache License 2.0. The upstream license, README, and changelog are kept with the asset files.

## Tripod table lamp

The source model in `assets/obstacles/table_lamp/tripod-table-lamp.glb` is the “Tripod - Tripod Table Lamp” model by Innerscene, obtained from [Innerscene's model page](https://www.innerscene.com/tools/library/3d-parts/tripod-tripod-table-lamp-276934ff). The page dedicates the source model to the public domain under CC0 1.0. The OBJ meshes in the same directory are geometry conversions of that source for MuJoCo. The project-specific conversion and collision proxies do not change the source model's CC0 dedication.

The root MIT license applies to Recovera's code. It does not replace or relicense these third-party assets.
